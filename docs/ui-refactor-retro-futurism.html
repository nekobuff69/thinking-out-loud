落地清单（三案共用）

  1. styles/global.css：把灰阶与三色收敛成 CSS 变量；补 @media 与 prefers-reduced-motion；删除死的 .state-label.checking/.error 规则。
  2. index.html + ui/*.css：改为「问题区 / 三栏 + History dock / 工具带」结构（以 docs/ui-refactor-b2-detail.html 为准）；问题区与三栏之间无分叉线、无节点、无分隔装置；问题区不承载功能按钮；M / S 保留并重绘。
  3. config.js：三家 color 改为双色系统下的频道标识（或降级为细标尺），pan 与 playbackOrder 不动。
  4. ui/column.js：去掉内联 style.color 注入，改由每列 CSS 变量驱动；保留 karaoke 词 span（高亮态换成底色／下划线，不再发光）；保留 M / S 回调。
  5. audio/waveform.js：镜像 FFT 柱改为标尺条或线框网格渲染，用 currentColor 取色，静默仍保留呼吸。
  6. index.js：删除 DebugOverlay 实例化、?debug 分支与 CSS 导入；保留 History、Mute/Solo、onStateChange；新增状态轨与交接时间轴的数据绑定。
  7. index.html：语义化 header / main，移除 debug 相关标记；删除孤儿模块 ui/mode-toggle.*。
  8. 文档与素材：README.md / CONTEXT.md / UBIQUITOUS_LANGUAGE.md 去掉 debug overlay 词条；docs/debug-overlay-reference.md 归档或删除；重录 demo 以匹配全英文列头（Buddhism / Confucianism / Daoism）。

三案均不改动 session / audio 数据链路。Mute、Solo 走现有 orchestrator.toggleMute/toggleSolo，History 走现有 SessionStore 与 replay 路径；移除 debug overlay 只影响诊断可见性，不影响 TTS 延迟／错误上报的事件总线（如需保留错误可见性，可把 pipeline-error 降级为状态轨里的一行文字）。
