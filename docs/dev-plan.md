# 改良计划

## 从专业领域转入大众文化

现有形式是用户提出问题，三个人工智能各自给出回答。现在的形式存在理解门槛高，观众理解大语言模型的基础原理并对底层技术好奇，有思考才能感受到，传播性较差。记起上个月参加vibe coding比赛，其中一件作品用鸡尾酒占卜，类似答案之书，为用户的提问给出一句话解答。一经展示，马上有现场观众主动试用。
受其启发，我想利用现有的“三声部”结构延伸到占卜、心理咨询领域。例如，三个ai 分别从“儒释道”的角度解答用户的疑问。将作品从ai技术领域转移到大众文化，借助中国人的文化基因，观众0门槛体验，起码有兴趣去试玩一下，使ai输出的答案成为谈资。

## 融入音乐强化听觉体验

编写生成式音乐代码，氛围音乐贯穿整个体验。待机时间解闷。ai作答时，用音乐掩饰ai发声的瑕疵，强化情绪感染力。
