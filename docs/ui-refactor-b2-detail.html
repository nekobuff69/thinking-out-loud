二、两项功能（不变）

功能行为影响范围
每列独立 visual点哪一列的波形区，就近菜单锚定并只作用于那一列；菜单标题带 CH 02 / WAVEFORM，四个选项各带实时预览与名字，点选即改该列并收起。其余两列完全不变。单列，不联动
V 键随机洗牌从四种动画中随机抽出三个互不相同的分配给三列，并保证新组合与当前不同；Shift+V 复位三列为默认 Oscilloscope。洗牌与复位都不打开菜单、不弹 notification，不产生任何遮挡。三列同时，随机重排而非统一赋值
shuffle 口径： 4 选 3 的随机排列，共 24 种组合，三列互不相同；若你要允许两列撞同一个动画，改一处抽样逻辑即可。Shift+V 的复位语义是本轮新分配的。

  5. Esc 优先级：波形菜单 → 选题面板 → History → 停止运行。

每列状态

  1. colVariants[] 独立保存，互不读写；渲染循环按列取分支。

  3. 菜单锚点按被点击列中心计算，指向线随列移动。
  4. 界面全英文、无中文提示、无分叉线、无节点与轮换动画、推挤式 History——全部保持不变。

六、实现清单（增量）

  1. config.js：waveform.defaultVariant: 'scope' + perColumn: true + 白名单；移除任何用于界面显示的 code 字段，只保留 name / short / 内部 id。
  2. index.js：维护 colVariants[]，按列实例化 createWaveform；工具带 WAVE 绑定三列名字字符串；V / Shift+V 绑定 shuffleVariants() / resetVariants()。
  3. ui/waveform-picker.js：open(targetColumnIndex) 接收被点列下标；选项只渲染预览与名字，无代号；setColumnVariant(i, id) 只改一列；不提供「应用到全部」；apply / shuffle / reset / 卡片应用都不触发 toast，仅 updateIndicators() 更新被动指示。
  4. ui/column.js：删除波形角标 DOM 与样式，波形容器内只有 canvas；cursor:pointer + hover 底色保留；其余 karaoke / M/S / 滚动逻辑不动。
  5. shuffleVariants()：Fisher–Yates 打乱四种 id 取前三个，互不相同且保证与当前组合不同；不打开菜单。
  6. audio/waveform.js：四分支 bars / scope / dots / radial 不变，setVariant() 每列实例各自调用；Oscilloscope 仍需 fftSize=1024 + getByteTimeDomainData()。
  7. 文案与文档：工具带、菜单、toast、aria-label、README / CONTEXT / UBIQUITOUS_LANGUAGE 一律用动画名字，不出现任何变体代号；重录 demo。
